# 🍎 Proyecto Alimentación

¡Hola! Este es tu proyecto personal de planificación de menús y lista de compras, diseñado especialmente para personas con **colesterol alto**.

## ¿Qué hace este programa?

Este sistema te ayuda a:

1. **Recibir menús semanales** completos (desayuno, comida, cena y merienda) adaptados a tu colesterol.
2. **Saber qué comprar** y en qué supermercado es más barato cada producto.
3. **Usar tus propias recetas** de Instagram o YouTube — solo envía el enlace y lo incluimos en tu menú (si es apto para tu colesterol).
4. **Todo por WhatsApp** — hablas con el sistema como si fuera un chat normal.

## ¿Necesitas saber programar?

**No.** Todo lo técnico ya está listo. Tú solo tienes que usar el chat de WhatsApp.

## ¿Cómo se usa?

Cuando el sistema esté funcionando, tú escribirás por WhatsApp:

- `"Quiero mi menú de esta semana"` → te envía el menú completo
- `"Lista de compras"` → te envía qué comprar y dónde es más barato
- Puedes enviar un enlace de Instagram o YouTube con una receta que quieras hacer
- Puedes decir qué comidas no te gustan o qué alergias tienes

## ¿Cuánto cuesta?

**Todo es gratuito.** Se usan solo herramientas gratuitas y de código abierto.

## ¿Quién lo creó?

Este proyecto fue creado especialmente para ti, siguiendo tus instrucciones al pie de la letra.
